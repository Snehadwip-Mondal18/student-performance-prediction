# Final Presentation Outline

**Title:** Student Academic Performance Prediction & Early-Warning System  
**Audience:** Faculty, academic advisors, project reviewers  
**Duration:** 7–10 minutes  
**Important:** This is a prototype demonstrated using synthetic data only.

1. **Problem and goal** — Why earlier supportive outreach may be useful.
2. **Data and target** — Explain the synthetic dataset, features and target definition.
3. **Data quality and EDA** — Show target distribution, attendance distribution and correlation matrix.
4. **Pipeline** — Validation → preprocessing → split → baseline/models → metrics.
5. **Model comparison** — Present recall, precision, F1, ROC-AUC and PR-AUC from `model_metrics.json` after running the code; do not invent results.
6. **Error trade-offs** — Explain false negatives and false positives with the confusion matrix.
7. **Recommendations and safeguards** — Human review, privacy, fairness, monitoring and supportive use only.
8. **Limitations and next steps** — Synthetic data are not real evidence; future validation is required.
